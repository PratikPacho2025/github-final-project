# GitHub Final Project

## Simple Interest Calculator

This project is a simple interest calculator that calculates interest based on the principal amount, annual rate of interest, and time period.

### Formula

Simple Interest = (Principal × Rate × Time) / 100

### Input

- Principal: The initial amount of money.
- Rate: The annual rate of interest in percentage.
- Time: The time period in years.

### Output

The calculator displays the simple interest calculated from the given inputs.

### Example

Principal = 1000

Rate = 5%

Time = 2 years

Simple Interest = 100

### Project File

The `simple-interest.sh` file contains the Bash script for calculating simple interest.
